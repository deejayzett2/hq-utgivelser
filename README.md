# HQ-utgivelser

Ferdige programpakker fra Nes IT-Hjelper, til bruk med HQ Launcher. Kildekoden til programmene ligger ikke her.

[Last ned HQ Launcher](../../releases/latest). Den finner, kontrollerer og oppdaterer resten av programmene selv. `katalog.json` er signert: launcheren installerer bare pakker den viser til.

[Veiledninger](veiledninger/README.md) til alle programmene.

Programmene krever gyldig lisens. Nedlasting herfra gir ikke rett til å bruke dem.

## FFmpeg

HQ Maestro-pakkene inneholder `ffmpeg.exe` og `ffprobe.exe`, uendrede bygg fra [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds). De er lisensiert under GNU GPL versjon 3 eller senere, og programmene kjører dem som egne prosesser. Lisensen ligger i `FFMPEG-LISENS.txt` i hver pakke.

Kildekoden til FFmpeg, bibliotekene og byggeskriptene ligger under [ffmpeg-kilde-2026-10](../../releases/tag/ffmpeg-kilde-2026-10). `KILDER.txt` viser hva som hører til hva.
