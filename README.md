# HQ-utgivelser

Ferdige programpakker fra Nes IT-Hjelper, til bruk med HQ Launcher. Kildekoden til programmene ligger ikke her.

Hent launcheren under [Releases](../../releases). Den finner, kontrollerer og oppdaterer resten av programmene selv. `katalog.json` er signert: launcheren installerer bare pakker den viser til.

Programmene krever gyldig lisens. Nedlasting herfra gir ikke rett til å bruke dem.
