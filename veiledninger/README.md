# Veiledninger

Kort om hvert program fra Nes IT-Hjelper og hvordan det brukes. Alle installeres og oppdateres med [HQ Launcher](../../../releases/latest).

| Program | Hva |
|---|---|
| [HQ Maestro Live](hq-live.md) | DJ-program for musikkvideoer, musikk og CD+G-karaoke |
| [HQ Maestro Alfa](hq-alfa.md) | Videoklipp med gjennomsiktig bakgrunn (WebM med alfa) |
| [HQ Maestro Videoboard](hq-videoboard.md) | Soundboard for video, med OBS og Stream Deck |
| [HQ Maestro Lightpad](hq-lightpad.md) | Kontrollflate for ShowXpress på mobil og nettbrett |
| [HQ Maestro Videomaker](hq-videomaker.md) | Musikkvideoer i takt med sangen |
| [Scoreboard](scoreboard.md) | Resultattavle for idrett og paintball |
| [E-Sport Updater](esport-updater.md) | Holder spillene på klubbens PC-er oppdatert |

Lisens kjøpes på [ithjelper.no](https://ithjelper.no). Uten lisens kan de fleste programmene prøves i 10 minutter per økt. E-Sport Updater kan bare vise PC-ene uten lisens.
